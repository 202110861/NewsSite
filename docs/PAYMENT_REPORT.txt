================================================================================
          경제인뉴스 후원(구독) 결제 시스템 현황 보고
================================================================================

문서 목적    : 후원 결제 기능 개발·테스트 현황 보고 및 실배포 전 준비 사항 정리
작성 기준일  : 2026년 7월 16일
결제 연동    : PortOne(아임포트) · 월 정기 후원(빌링키 방식)


--------------------------------------------------------------------------------
1. 보고 요약
--------------------------------------------------------------------------------

본 프로젝트의 후원 기능은 PortOne을 통해 월 정기 구독 결제를 제공하도록
구현하였습니다.

  [활성 결제 수단]
    · 토스페이
    · 카카오페이

  [PortOne 테스트 연동]
    · 완료 (토스페이·카카오페이 모두 구독 ACTIVE 상태까지 검증 완료)

  [실서비스 배포]
    · 미완료 — 토스페이·카카오페이 PG 실계약 및 PortOne 실연동 전환 필요

  [보류 결제 수단]
    · 휴대폰 소액결제(다날), 케이뱅크, 카카오뱅크, 네이버페이
    · 코드 및 DB 스키마에만 보존, 브라우저(사용자 화면)에는 미노출

결론적으로, 기술 구현과 PortOne 테스트 환경 검증은 완료되었으나, 실제
서비스 배포 및 실결제를 위해서는 토스페이·카카오페이와의 가맹점 실계약이
우선적으로 진행되어야 합니다. 계약 완료 후 PortOne 실연동 채널 등록 및
서버 환경 설정 전환만으로 실결제 오픈이 가능하도록 개발되어 있습니다.


--------------------------------------------------------------------------------
2. 결제 수단별 현황
--------------------------------------------------------------------------------

2-1. 활성 결제 수단 (브라우저 노출 · 신규 구독 가능)

  (1) 토스페이
      - PG : tosspay_v2
      - 방식 : 정기결제(빌링키)
      - 테스트 : 구독 ACTIVE 확인 완료

  (2) 카카오페이
      - PG : kakaopay.TCSUBSCRIP (정기결제)
      - 방식 : 정기결제(빌링키)
      - 테스트 : 구독 ACTIVE 확인 완료

  ※ 후원 페이지(/support)에는 토스페이·카카오페이만 노출됩니다.


2-2. 보류 결제 수단 (코드만 작성 · 브라우저 미노출)

  아래 결제 수단은 삭제하지 않고 소스 코드 및 데이터베이스에만 보존해
  두었으며, 사용자에게는 표시하지 않습니다.

  (1) 휴대폰 소액결제 (다날)
      - 보류 사유 : PG 가입비 약 20만 원 등 비용 부담

  (2) 케이뱅크 (내통장결제)
      - 보류 사유 : PG 가입·운영 비용 부담

  (3) 카카오뱅크 (내통장결제)
      - 보류 사유 : PG 가입·운영 비용 부담

  (4) 네이버페이
      - 보류 사유 : 우선순위 조정(토스페이로 대체), 코드는 주석 처리로 보존

  ※ 가입비·계약 부담이 큰 다날 휴대폰·내통장결제 대신, 토스페이·카카오페이를
    주력 결제 수단으로 채택하였습니다.


--------------------------------------------------------------------------------
3. PortOne 테스트 연동 완료 내역
--------------------------------------------------------------------------------

  테스트 모드(PAYMENT_MODE=portone_test) 기준으로 아래 항목을 검증 완료하였습니다.

  · 토스페이 : 빌링키 발급 → 결제 완료 → 마이페이지 구독 ACTIVE 확인
  · 카카오페이 : 빌링키 발급 → 결제 완료 → 마이페이지 구독 ACTIVE 확인
  · PortOne 테스트 채널 연동 (토스·카카오 채널 키 설정)
  · 정기결제 예약 및 웹훅 엔드포인트 구현 (/api/payments/webhook)

  참고 : 테스트 모드에서는 빌링키 등록 시 0원 처리 등이 적용될 수 있으며,
        실연동 시에는 실제 플랜 금액이 청구됩니다.


--------------------------------------------------------------------------------
4. 실배포 전 선행 조건
--------------------------------------------------------------------------------

  실서비스 오픈 전 아래 순서로 진행해야 합니다.

  ① 사이트·약관·사업자 정보 준비
           ↓
  ② 토스페이 가맹점 실계약
  ③ 카카오페이 정기결제 실계약  (②·③ 병렬 진행 가능)
           ↓
  ④ PortOne 실연동 채널 등록 (운영 CID·채널 키)
           ↓
  ⑤ 서버 배포 및 PAYMENT_MODE=portone_live 전환
           ↓
  ⑥ 소액 실결제 검증 → 서비스 오픈

  추가 코드 개발 없이, PG 계약·PortOne 콘솔 설정·환경변수 전환만으로
  실결제 전환이 가능합니다.


--------------------------------------------------------------------------------
5. PG 계약 시 사이트·서류 준비 사항
--------------------------------------------------------------------------------

  PG(토스·카카오) 심사 및 PortOne 실연동 신청 전, 아래 항목을 갖추어야 합니다.


5-1. 사이트 필수 정보 (화면 노출)

  1.  서비스 URL
      실제 결제 연동·배포 도메인 (HTTPS). PG 심사 시 접속 확인.

  2.  상호
      사업자등록증 상 법인/상호명. 사이트 하단 필수 노출.

  3.  사업자등록번호
      10자리 사업자 번호. 사이트 하단 필수 노출.

  4.  대표자명
      사업자등록증 상 대표자 성명. 사이트 하단 필수 노출.

  5.  사업장 주소
      사업자등록증 상 소재지. 사이트 하단 필수 노출.

  6.  유선 전화
      고객센터 연락처. 휴대폰 번호는 인정되지 않는 경우가 많으므로
      유선 번호 사용 권장. 사이트 하단 필수 노출.

  7.  고객센터 이메일
      문의·CS용 이메일 주소. 사이트 하단 필수 노출.

  8.  후원·구독 페이지
      플랜명, 금액, 결제 수단, 월 정기 과금 안내 포함 (/support).

  9.  판매 상품(구독 플랜)
      구독 플랜 3개 이상 등록·노출 권장 (PG 심사 요건).

  10. 해지 방법 안내
      마이페이지 등에서 구독 해지가 가능해야 함 (정기결제 심사 필수).


5-2. 법적 문서 (페이지 게시·링크)

  1.  이용약관
      서비스 이용 조건, 구독·결제·해지, 환불 정책, 책임 범위 등 포함.

  2.  개인정보처리방침
      수집 항목, 이용 목적, 보관 기간, 제3자 제공(PG·PortOne 등), 파기
      절차 등 포함.

  3.  정기결제(구독) 안내
      매월 자동 결제, 결제일 기준, 해지 시 즉시 중단 등
      (이용약관 또는 별도 페이지).


5-3. 제출 서류 (PG 계약 시 일반적 요구)

  1.  사업자등록증          (사업자 등록 완료)
  2.  대표자 신분증
  3.  통장 사본             (정산 계좌)
  4.  등기부등본            (법인 해당 시)
  5.  주주명부              (법인 해당 시)
  6.  인감증명서            (법인 해당 시)
  7.  정기결제 이용특약서    (카카오페이 정기결제 신청 시 별도 필수)


5-4. 계약서 기재 사항 (카카오페이 정기결제 예시)

  · 정기결제 이용 여부     : 이용
  · 정기결제 대상 품목     : 예) 뉴스 콘텐츠 월 구독, 온라인 미디어 후원
  · 홈페이지 주소          : 실제 서비스 URL
  · 구독 주기              : 1개월 (카카오 정기결제는 1개월 이내 주기만 허용)


--------------------------------------------------------------------------------
6. 카카오페이 실계약 절차
--------------------------------------------------------------------------------

6-1. 개요

  · 용도 : 월 정기 후원(빌링키). 테스트 CID(TCSUBSCRIP)와 별도로
          실운영 CID(CA로 시작)를 발급받아야 합니다.
  · 신청 : PortOne 안내 또는 카카오페이 가맹점센터
  · 문의 : 전화 1644-7108 / 이메일 kakaopay_biz@kakaopay.com


6-2. 진행 순서

  1) 5장 체크리스트에 따른 사이트·약관·사업자 정보 준비
  2) 카카오페이 가맹점 신청 — 정기결제(구독) 명시, 정기결제 이용특약서 제출
  3) 온라인 전자계약·서류 심사·카드사 심사 (통상 1~3주 이상)
  4) 승인 후 정기결제 CID(CA...) 이메일 수신
  5) PortOne 콘솔 실연동 → 카카오페이 채널 추가 → CID 입력 → 채널 키 발급
  6) 서버 환경변수 반영 후 실결제 테스트


6-3. PortOne 실연동 채널 설정

  · 연동 모드      : 실연동
  · 결제대행사     : 카카오페이
  · 결제모듈       : 결제창 일반/정기결제
  · PG상점아이디   : 발급받은 CA... 정기결제 CID

  ※ 일반결제 CID와 정기결제 CID는 별도 발급됩니다.
    구독 서비스에는 정기결제 CID만 사용합니다.


6-4. 실연동 시 환경변수 변경

  PAYMENT_MODE=portone_live
  PORTONE_KAKAO_CHANNEL_KEY=(실연동 채널 키)
  PORTONE_KAKAO_PG=kakaopay.(실제 정기결제 CID)
  ※ 테스트용 kakaopay.TCSUBSCRIP 은 반드시 실 CID로 변경해야 합니다.


--------------------------------------------------------------------------------
7. 토스페이 실계약 절차
--------------------------------------------------------------------------------

7-1. 개요

  · 용도 : 월 정기 후원(빌링키), PG tosspay_v2
  · 신청 : 토스페이 가맹점 (https://toss.im/tosspay)
  · 승인 후 : 토스페이 가맹점 관리자에서 MID(상점아이디), API Key 확인


7-2. 진행 순서

  1) 5장 체크리스트에 따른 사이트·약관·사업자 정보 준비
  2) 토스페이 가맹점 신청 및 서류 제출
  3) 심사·승인 (MID, API Key 발급)
  4) PortOne 콘솔 실연동 → 토스페이 v2 채널 추가 → MID·API Key 입력
  5) 서버 환경변수 반영 후 실결제 테스트


7-3. 실연동 시 환경변수 변경

  PAYMENT_MODE=portone_live
  PORTONE_TOSS_CHANNEL_KEY=(실연동 채널 키)
  PORTONE_TOSS_PG=tosspay_v2


--------------------------------------------------------------------------------
8. PortOne 실연동 및 배포 설정
--------------------------------------------------------------------------------

8-1. PortOne 콘솔

  · 테스트 모드에서 실연동 모드로 전환
  · API 키(IMP_CODE, API_KEY, API_SECRET) 실연동 탭에서 재확인
  · 웹훅 URL : https://(API도메인)/api/payments/webhook
    → 실연동 Notification에 등록, 호출 테스트 200 응답 확인


8-2. 배포 환경변수 (예시)

  PAYMENT_MODE=portone_live
  PORTONE_IMP_CODE, PORTONE_API_KEY, PORTONE_API_SECRET
  PORTONE_TOSS_CHANNEL_KEY, PORTONE_KAKAO_CHANNEL_KEY (실연동 채널 키)
  PORTONE_TOSS_PG=tosspay_v2
  PORTONE_KAKAO_PG=kakaopay.(실제 정기결제 CID)
  CLIENT_URL=https://(실제 프론트 도메인)
  API_PUBLIC_URL=https://(실제 API 도메인)
  NODE_ENV=production


8-3. 테스트 vs 실연동 차이

  · 채널 키     : 테스트 채널 → 실연동 채널로 교체
  · 카카오 PG   : kakaopay.TCSUBSCRIP → kakaopay.(실제CID)
  · 첫 결제     : 테스트 0원 빌링키 등록 가능 → 실연동 실제 플랜 금액 청구
  · 웹훅 URL    : ngrok 등 임시 URL → 운영 HTTPS 도메인


--------------------------------------------------------------------------------
9. 배포 후 검증 항목
--------------------------------------------------------------------------------

  · 토스페이 실결제 1건 → 구독 ACTIVE → PortOne 실연동 결제 내역 확인
  · 카카오페이 실결제 1건 → 동일 확인
  · PortOne 콘솔에서 1개월 후 정기결제 예약 건 존재 확인
  · 마이페이지에서 다음 자동결제 예약 안내 확인
  · 구독 해지 → PortOne 예약 취소 → 재가입 가능 여부 확인
  · (선택) 웹훅 paid/failed 수신 동작 확인

10. 예상 일정 (참고)
