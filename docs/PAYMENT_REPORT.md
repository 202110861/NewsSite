# 후원 결제 시스템 현황 및 실배포 가이드

> **문서 목적:** 경제인뉴스 후원(구독) 결제 기능의 개발·테스트 현황을 보고하고, 실서비스 배포를 위해 필요한 PG 계약 및 사이트 준비 사항을 정리합니다.  
> **작성 기준일:** 2026-07-16  
> **결제 연동:** PortOne(아임포트) · 월 정기 후원(빌링키)

---

## 1. 요약

| 구분 | 상태 |
|------|------|
| **활성 결제 수단** | 토스페이, 카카오페이 |
| **PortOne 테스트 연동** | ✅ 완료 (토스·카카오 구독 ACTIVE 확인) |
| **실서비스 배포** | ⬜ PG 실계약 및 PortOne 실연동 전환 필요 |
| **보류 결제 수단** | 휴대폰(다날), 케이뱅크, 카카오뱅크, 네이버페이 — 코드만 보존, 브라우저 미노출 |

**핵심:** 기술 구현과 PortOne **테스트** 검증은 완료되었습니다. 실제 배포·실결제를 위해서는 **토스페이·카카오페이 가맹점 실계약**이 우선되어야 하며, 이후 PortOne **실연동** 채널 및 서버 환경변수 전환이 필요합니다.

## 2. 결제 수단별 현황

### 2-1. 활성 (브라우저 노출 · 신규 구독 가능)

| 결제 수단 | PG | 테스트 | 비고 |
|-----------|-----|--------|------|
| **토스페이** | `tosspay_v2` | ✅ ACTIVE 확인 | 정기결제(빌링키) |
| **카카오페이** | `kakaopay.TCSUBSCRIP` | ✅ ACTIVE 확인 | 정기결제(빌링키) |

- 후원 페이지(`/support`) UI: **1행 — 토스페이 · 카카오페이**
- API 허용 수단: `ACTIVE_PAY_METHODS = ['KAKAO_PAY', 'TOSS_PAY']`

### 2-2. 보류 (코드만 작성 · 브라우저 미노출)

아래 수단은 **삭제하지 않고 코드·DB 스키마에만 보존**되어 있으며, **사용자에게는 표시되지 않습니다.**

| 결제 수단 | 연동 방식 | 보류 사유 |
|-----------|-----------|-----------|
| **휴대폰 소액결제** | 다날(Danal) | PG 가입비 약 **20만 원** 등 비용 부담 |
| **케이뱅크** | 내통장결제(`settle_acc`) | 동일 계열 PG 가입·운영 비용 |
| **카카오뱅크** | 내통장결제(`settle_acc`) | 동일 계열 PG 가입·운영 비용 |
| **네이버페이** | `naverpay` | 우선순위 조정(토스페이로 대체), 코드 주석 보존 |

**대안 전략:** 가입비·계약 부담이 큰 다날 휴대폰·내통장결제 대신, **토스페이·카카오페이**를 주력 결제 수단으로 채택하였습니다.

## 3. PortOne 테스트 연동 완료 내역

다음 항목은 **테스트 모드**(`PAYMENT_MODE=portone_test`) 기준으로 검증 완료되었습니다.

- [x] 토스페이: 빌링키 발급 → 결제 완료 → 마이페이지 **구독 ACTIVE**
- [x] 카카오페이: 빌링키 발급 → 결제 완료 → 마이페이지 **구독 ACTIVE**
- [x] PortOne 테스트 채널 연동 (`PORTONE_TOSS_CHANNEL_KEY`, `PORTONE_KAKAO_CHANNEL_KEY`)
- [x] 정기결제 예약·웹훅 엔드포인트 구현 (`/api/payments/webhook`)

> 테스트 모드에서는 빌링키 등록 시 **0원** 처리 등이 적용될 수 있으며, 실연동 시에는 **실제 플랜 금액**이 청구됩니다.

## 4. 실배포 전 선행 조건

실서비스 오픈 전 **반드시** 아래 순서로 진행해야 합니다.

```
① 사이트·약관·사업자 정보 준비
        ↓
② 토스페이 가맹점 실계약
③ 카카오페이 정기결제 실계약  (병렬 진행 가능)
        ↓
④ PortOne 실연동 채널 등록 (운영 CID·채널 키)
        ↓
⑤ 서버 배포 + PAYMENT_MODE=portone_live
        ↓
⑥ 소액 실결제 검증 → 서비스 오픈
```

**코드 추가 개발 없이** 환경변수·PortOne 콘솔 설정·PG 계약만으로 실결제 전환이 가능하도록 구현되어 있습니다.

## 6. 카카오페이 실계약 절차

### 6-1. 개요

- **용도:** 월 정기 후원(빌링키) — 테스트 CID `TCSUBSCRIP`과 별도로 **실운영 CID**(`CA`로 시작) 발급
- **신청 경로:** PortOne 안내 또는 카카오페이 가맹점센터
  - 전화: **1644-7108**
  - 이메일: **kakaopay_biz@kakaopay.com**
- **참고:** [PortOne — 카카오페이 계약 시 참고사항](https://help.portone.io/content/kakaopay-contract)

### 6-2. 진행 순서

1. **5장 체크리스트** 사이트·약관·사업자 정보 준비
2. 카카오페이 가맹점 신청 — **정기결제(구독)** 명시, **정기결제 이용특약서** 제출
3. 온라인 전자계약·서류 심사·카드사 심사 (통상 1~3주 이상)
4. 승인 후 **정기결제 CID** (`CA...`) 이메일 수신
5. PortOne 콘솔 → **실연동** → 카카오페이 채널 추가 → CID 입력 → **채널 키** 발급
6. 서버 env 반영 후 실결제 테스트

### 6-3. PortOne 실연동 채널 설정

| 필드 | 값 |
|------|-----|
| 연동 모드 | **실연동** |
| 결제대행사 | 카카오페이 |
| 결제모듈 | 결제창 일반/정기결제 |
| PG상점아이디 (CID) | 발급받은 **`CA...` 정기결제 CID** |

### 6-4. 환경변수 (실연동 시 변경)

```env
PAYMENT_MODE=portone_live
PORTONE_KAKAO_CHANNEL_KEY=channel-key-실연동-카카오...
# 테스트용 TCSUBSCRIP → 실 CID로 변경 필수
PORTONE_KAKAO_PG=kakaopay.CA1234567890
```

> 일반결제 CID와 정기결제 CID는 **별도 발급**됩니다. 구독 서비스에는 **정기결제 CID**만 사용합니다.

## 7. 토스페이 실계약 절차

### 7-1. 개요

- **용도:** 월 정기 후원(빌링키) — PG `tosspay_v2`
- **신청:** [토스페이 가맹점](https://toss.im/tosspay) 사업자 신청
- **승인 후:** 토스페이 가맹점 관리자 → **MID(상점아이디)**, **API Key** 확인

### 7-2. 진행 순서

1. **5장 체크리스트** 사이트·약관·사업자 정보 준비
2. 토스페이 가맹점 신청 및 서류 제출
3. 심사·승인 (MID, API Key 발급)
4. PortOne 콘솔 → **실연동** → 토스페이 v2 채널 추가 → MID·API Key 입력 → **채널 키** 발급
5. 서버 env 반영 후 실결제 테스트

### 7-3. 환경변수 (실연동 시 변경)

```env
PAYMENT_MODE=portone_live
PORTONE_TOSS_CHANNEL_KEY=channel-key-실연동-토스...
PORTONE_TOSS_PG=tosspay_v2
```

## 8. PortOne 실연동 및 배포 설정

### 8-1. PortOne 콘솔

| 항목 | 내용 |
|------|------|
| 실연동 전환 | 테스트 → **실연동** 모드 |
| API 키 | `PORTONE_IMP_CODE`, `PORTONE_API_KEY`, `PORTONE_API_SECRET` (실연동 탭에서 재확인) |
| 웹훅 URL | `https://{API도메인}/api/payments/webhook` — **실연동** Notification에 등록, 호출 테스트 200 확인 |

### 8-2. 서버 환경변수 (배포 환경 예시)

```env
PAYMENT_MODE=portone_live

PORTONE_IMP_CODE=impXXXXXX
PORTONE_API_KEY=...
PORTONE_API_SECRET=...

PORTONE_TOSS_CHANNEL_KEY=...    # 실연동 채널 키
PORTONE_KAKAO_CHANNEL_KEY=...   # 실연동 채널 키
PORTONE_TOSS_PG=tosspay_v2
PORTONE_KAKAO_PG=kakaopay.CA... # 실제 정기결제 CID

CLIENT_URL=https://실제-프론트-도메인
API_PUBLIC_URL=https://실제-API-도메인
NODE_ENV=production
```

### 8-3. 테스트 vs 실연동 차이

| 항목 | `portone_test` | `portone_live` |
|------|----------------|----------------|
| 채널 키 | 테스트 채널 | **실연동 채널** |
| 카카오 PG | `kakaopay.TCSUBSCRIP` | `kakaopay.{실제CID}` |
| 첫 결제 금액 | 0원 빌링키 등록 가능 | **실제 플랜 금액 청구** |
| 웹훅 | ngrok 등 | **운영 HTTPS 도메인** |

## 9. 배포 후 검증 체크리스트

- [ ] 토스페이 실결제 1건 → 구독 ACTIVE → PortOne 실연동 결제 내역 확인

- [ ] 마이페이지: 다음 자동결제 예약 안내
- [ ] 구독 **해지** → PortOne 예약 취소 → **재가입** 가능
- [ ] (선택) 웹훅 `paid` / `failed` 수신 동작 확인

## 12. 결론

- **휴대폰(다날)·케이뱅크·카카오뱅크·네이버페이**는 가입비·운영 정책상 **UI에 노출하지 않으며**, 코드만 유지합니다.
- **토스페이·카카오페이**는 PortOne 테스트 환경에서 **구독 ACTIVE까지 검증 완료**되었습니다.
- **실제 배포**를 위해서는 **토스페이·카카오페이 가맹점 실계약**이 선행되어야 하며, **5장의 사이트 정보·약관·서류**를 먼저 준비하는 것이 심사 통과에 필수적입니다.
- 계약·CID·채널 키 확보 후 `PAYMENT_MODE=portone_live` 및 운영 URL로 전환하면 실결제 서비스 오픈이 가능합니다.
